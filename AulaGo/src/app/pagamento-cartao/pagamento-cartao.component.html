Pagamento com Cartão

O número do cartão é obrigatório.
O número do cartão deve conter 16 dígitos no formato correto.
A validade do cartão é obrigatória.
A validade deve estar no formato MM/AA.
O código CVV é obrigatório.
O código CVV deve conter 3 ou 4 dígitos.
O nome do titular é obrigatório.
O nome deve conter apenas letras e espaços, sem números ou símbolos.
